# Phase 6P：推理阶段物理可达性上限审计

状态：`v1 frozen before first CUDA output`

## 1. 研究问题

Phase 4C 的地震制导使硬地震 RMSE 从 `0.04226184` 降到
`0.03904787`，仅达到约 `7.6%` 的残差消除率；最终制导地震场仍更像
基线而不是真值观测。这个事实不能单独用地球物理反演非唯一性解释，
因为当前样本尚未充分到达观测流形。

Phase 6P 要区分三个机制：

1. 轨迹控制不足：物理目标在冻结表示中可达，但原有逐步制导太弱；
2. 表示或软硬桥接不足：即使直接强制优化冻结网络的连续终点，也无法使
   最终硬标签正演充分逼近观测；
3. 非唯一性或目标错位：最终硬地震已经逼近观测，但三维地质仍未逼近
   真值。

本阶段是诊断实验，不训练网络、不更新 EMA 基础模型，也不构成真实观测
或泛化证据。

## 2. 固定资产

- EMA checkpoint、`cond_generation_0` 真值/钻孔条件；
- Phase 4C `distinct_upper_bound_v1_fix2` 不可变观测及声学码本；
- Phase 4C seed-42、32 步、alpha-zero 历史基线；
- 正演、采样掩膜、不确定性和硬地震损失定义全部沿用 Phase 4C。

任何输入哈希不一致都必须在优化前失败。初始硬样本必须逐体素等于历史
alpha-zero 基线。

## 3. Phase 6P-B：终点物理拟合上界（本次实现）

从历史基线的连续终点状态开始，冻结模型全部参数，只把连续终点状态
作为 Adam 参数。每次更新执行：

1. 用温度退火的 soft decode 构造声阻抗/慢度；
2. 计算与 Phase 4C 相同的可微地震损失；
3. 在条件位置将梯度清零；
4. 对梯度裁剪并更新终点状态；
5. 对每个体素施加冻结范数护栏，再精确投影钻孔和地表条件；
6. 每 5 步硬解码、硬正演，只按硬地震损失保存最优状态。

冻结温度计划为 `0.5×40, 0.2×60, 0.1×60, 0.05×40`，共 200 次
更新。禁止在该 legacy case 上做超参数扫描。

运行器不得计算全局 IoU、目标体 IoU、真值连通体恢复率等地质真值指标，
也不得用它们早停或选样。真值文件仅可用于既有条件构造、不可变观测一致性
校验和条件违例检查。

## 4. 独立真值审计

优化完成后，由独立审计器读取已经冻结的 `baseline_sample.pt` 与
`best_sample.pt`，再计算三维地质指标。审计不得反向改变优化结果或配置。

物理达到率定义为：

`A = 1 - RMSE(best, observed) / RMSE(baseline, observed)`

- `A < 0.25`：低可达；
- `0.25 <= A < 0.80`：部分可达；
- `A >= 0.80`：高可达。

同时记录场更新相对所需残差的范数比及两者余弦，判断更新是否足量且方向
正确。地质“实质改善”在本冻结审计中定义为目标体 IoU 至少提高 `0.10`，
或真值中实际出现类别的 mean-IoU 至少提高 `0.05`。

## 5. 验收门

工程门必须全部通过：

- EMA 基础模型参数哈希前后完全一致且无梯度；
- 历史基线逐体素回归通过；
- 所有状态、梯度、损失有限；
- 条件体素零违例；
- 最优状态确由最低硬地震损失选出；
- 配置、源代码、输入和输出同时记录文件哈希与 tensor-content 哈希。

结果门和下一步：

| 物理达到率 | 独立地质审计 | 结论（限于本协议） | 下一步 |
|---|---|---|---|
| 低 | 任意 | 冻结表示/soft-hard 桥接是主要瓶颈 | 进入训练路线，不再扩大推理权重 |
| 部分 | 任意 | 可达性存在但仍不足 | 执行 Phase 6P-C 轨迹内 proximal 校正一次 |
| 高 | 明显改善 | 原轨迹控制不足 | 研究更稳定的轨迹内物理校正，再决定是否训练 |
| 高 | 无明显改善或退化 | 物理目标可达但地质不识别，支持非唯一性/目标错位解释 | 训练必须加入地质先验、局部/多属性约束和 held-out 验证 |

“低可达”不是数学上的不可达证明，只表示在预先冻结、强于原制导的 200 步
终点优化协议内仍不可达。

## 6. 后续完整矩阵

Phase 6P-B 首先在主要的 Phase 4C 地震案例运行。Phase 6P-A 随后用与
Phase 4C 完全相同的 32 步轨迹执行 `0.25, 0.5, 1, 2, 4` 强度/上限
阶梯。各级共享 seed 和观测，按物理指标并列报告，不用真值选择强度；
`0.25` 级必须逐体素回归既有 Phase 4C 制导样本。若工程门通过，再按相同
审计逻辑补充：

- 正确、零值和打乱观测控制；
- Phase 3 sigma-1 与 Phase 4 gravity 次要案例；
- 仅在终点高可达、原轨迹低可达时运行 Phase 6P-C。

在用户确认前，本协议不授权 Phase 6B 或其他正式适配器训练。
