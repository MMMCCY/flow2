# Phase 6P report：推理阶段地震物理可达性极限审计

完成日期：2026-08-02。

## 决策

**LOW REACHABILITY：在冻结网络、同一 seed 和同一 Phase 4C 观测下，把轨迹
制导速度上限从先验速度的 0.25 倍提高到 4 倍，最终硬地震最多只消除 9.88%
的基线 RMSE；直接对连续终点做 200 步物理优化也只消除 1.69%。继续增强干涉
会大幅破坏三维地质，却不能把硬地震推到观测流形。**

因此，当前 notebook 中“制导地震更像基线而不是真值”的主要原因不是已经达到
物理等价解后的非唯一性。当前样本首先没有充分拟合地震观测；冻结流的轨迹速度、
soft acoustic proxy 和最终 hard decode 之间存在严重错位。结果支持进入学习型
Phase 6B/6C 路线，不支持继续在旧案例上提高推理权重。

这是同一样本、truth-derived inverse-crime 下的机制诊断，不是跨样本泛化证据，
也不是冻结表示在数学意义上的不可达证明。

## 实验 1：原 Phase 4C 轨迹的极限制导阶梯

五个级别在 GPU 输出前同时冻结：`alpha=max_guidance_ratio` 分别为
`0.25, 0.5, 1, 2, 4`。其余设置完全等于 Phase 4C：EMA、seed 42、32 步
fixed Euler、cosine `tau 0.5 -> 0.1`、windowed-sine、reference-gradient
scaling、相同不可变观测和硬条件。

运行器不计算地质真值指标。所有级别完成后，独立审计器才打开真值。alpha-zero
基线逐体素回归历史基线，0.25 级逐体素回归历史 Phase 4C 制导样本。

| 强度/上限 | 硬地震 RMSE | RMSE 达到率 | 场更新/所需残差范数 | 更新方向余弦 | 改动体素 | Δ全局 mIoU | Δ目标 IoU | Δ目标 recall |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 0.25 | 0.03904787 | 7.60% | 0.725 | 0.463 | 1.43% | -0.0411 | -0.0027 | -0.0078 |
| 0.50 | 0.03830707 | 9.36% | 0.791 | 0.508 | 2.18% | -0.0414 | -0.0051 | -0.0126 |
| 1.00 | **0.03808441** | **9.88%** | 0.886 | 0.549 | 4.14% | -0.0435 | -0.0068 | -0.0166 |
| 2.00 | 0.03964071 | 6.20% | 1.006 | 0.563 | 10.37% | -0.0544 | -0.0143 | -0.0295 |
| 4.00 | 0.04038906 | 4.43% | 1.081 | 0.581 | 29.90% | -0.0909 | -0.0153 | -0.0304 |

基线硬地震 RMSE 为 `0.04226184`。强度 1.0 是物理最优；到 2/4 倍时，场更新
范数已经等于或超过需要消除的完整残差，但方向余弦只有约 0.56/0.58，因此大量
更新在错误方向。4 倍改变 78,390 个体素，全局 mIoU 从 `0.19291` 降到
`0.10201`，目标 IoU 从 `0.02860` 降到 `0.01334`，但地震达到率反而低于
1 倍级别。

这排除了“0.25 cap 是主要瓶颈”。上限偏低只解释从 7.60% 到 9.88% 的小幅差异。

## 实验 2：冻结网络的连续终点物理拟合

第二个诊断绕开 32 步生成轨迹，从严格回归的连续基线终点开始，只优化这个终点
状态。基础网络和 embedding 全部冻结。Adam 执行 200 次更新，温度计划为
`0.5×40, 0.2×60, 0.1×60, 0.05×40`；每步投影精确条件并施加体素范数
护栏。checkpoint 只按硬标签正演损失选择，地质真值指标仍由运行后的独立审计器
计算。

- 最佳硬状态出现在第 15 步；
- 硬地震 RMSE `0.04226184 -> 0.04154664`，达到率仅 `1.69%`；
- 软地震 RMSE 从第 1 步的 `0.03177387` 持续降到第 200 步的
  `0.01682162`，约降低 47%；
- 同期最终硬地震 RMSE 却升到 `0.09732279`；
- 最佳硬场更新/所需残差范数为 `0.459`，方向余弦仅 `0.266`；
- 最佳硬样本只改变 1,003 个体素（0.383%），目标 IoU仅
  `+0.00055`，全局 mIoU 反而 `-0.01590`。

这直接证明了当前 soft acoustic objective 与最终离散标签正演之间存在严重
relaxation gap：连续混合属性可以很好地拟合地震，但降温和 argmax 不会保留该
拟合，甚至会使硬响应变差。连续 loss 下降不能作为成功证据。

## 为什么 Phase 2 好、Phase 3/4 差

Phase 2 的全分辨率双属性 oracle 在每个体素直接提供区分类别的码字，梯度与
embedding 决策边界近似局部对齐；它没有空间降质，也没有把三维类别压缩为低维
响应。Phase 3 模糊后，一个观测位置混合邻域类别，类别边界信息显著丢失。
Phase 4C 又经过界面反射、时间深度映射和子波卷积；地震主要约束阻抗对比而非
每个体素的绝对岩性，三维到数据域的映射更非局部、欠定。

冻结网络从未以“某个地震残差方向应对应哪种地质速度修正”为目标训练。现有
采样器只能把物理梯度作为横向速度叠加到强先验轨迹上。弱时改变不了足够多的
hard labels；强时则离开生成器熟悉的地质流形。终点实验进一步表明，即使绕过
先验速度，soft mixture 也能投机性拟合而不产生正确的 hard categories。

## 非唯一性应如何解释

如果非唯一性是当前视觉差异的主要解释，应先观察到硬地震达到率较高，再看到
三维地质仍不接近真值。Phase 6P 的最高达到率只有 9.88%，不满足这个前提。
因此当前结果只能说明：

1. 首要问题是物理目标在现有冻结推理路径中低可达；
2. 在达到观测流形之后仍很可能存在非唯一性，但本实验尚未进入那个区域；
3. 高强度下地质与物理同时变差/饱和，是更新方向错位，不是“另一组同样正确的
   地球物理解”。

## 工程验收

两组实验的工程门全部通过：

- EMA 基模 tensor hash 前后相同，基模梯度为空；
- alpha-zero 历史基线精确，0.25 轨迹级历史样本精确；
- 条件违规为零，所有损失/梯度/状态有限；
- endpoint 最优状态严格按最低硬地震损失选择；
- runner 不计算或选择地质真值指标；
- 独立审计器验证每个保存文件的 file hash、raw tensor hash 和分类内容的
  canonical int64 hash；
- RTX 4090 D 峰值分配显存约 0.69 GB（endpoint）和 1.83 GB（ladder）。

## 证明边界与下一步

Phase 6P 证明：在已测试且明显强于 Phase 4C 的冻结推理协议内，单纯提高物理
权重不能得到物理一致且地质正确的 hard 3-D 模型；soft-hard gap 与未学习的
地震到地质修正映射是主要瓶颈。

它没有证明网络内部完全没有任何地震相关可用特征，也没有穷尽所有离散优化器、
反演方法或所有地质先验。结论应表述为“当前冻结生成器 + 当前 soft decoder +
当前推理控制器低可达”，而不是绝对不可达。

建议保持既定 Phase 6B 顺序：先建立按完整 geology history 分组、无泄漏、可审计
的数据 manifest，再做 held-out oracle/degraded-feature adapter pilot。训练目标必须
同时处理：

- all-class categorical/decoder-margin 或等效 hard-aware 目标，防止 soft mixture
  投机；
- 低权重物理一致性，防止 Phase 6A 只改善 geology 却恶化 seismic；
- correct/zero/shuffled observation 控制，证明网络确实使用地球物理；
- paired baseline、条件精确、基模冻结、held-out hard geology 与 hard seismic
  双重验收。

在用户确认前，Phase 6P 不授权正式适配器训练。
