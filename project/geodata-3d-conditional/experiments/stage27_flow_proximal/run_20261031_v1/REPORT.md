## 实施与范围

原模型和 embedding 冻结，411项 EMA，15维 embedding，网络 FP32（关闭 TF32/autocast），近端物理 FP64。近端设备为 cuda。每臂32次速度前向；使用原 seed42 保存源，各步CPU FP32独立噪声种子1042+j，各臂hash逐项相同。

每步以 no_grad 计算 e_hat=x+(1-t)v，并 detach；仅在地下非原条件域对终点做固定3次近端尝试。目标为自由元素均值信赖项，加 nu² 倍的平方相对地震能量和0.05倍平滑TV。梯度乘D_free，方向RMS封顶0.1，按封存六步长Armijo搜索。更新后按 b*u+(1-b)*epsilon 重投影，所有非自由位置始终恢复原条件嵌入。无跨步/网络反传，无新硬伪井，无传统反演、训练、扫描或补充seed。

checkpoint训练时间范围为[0.0001,0.9999]，首步名义0在1e-4评估是明确数值近似。源码训练终点另有1e-4 Gaussian jitter；训练路径仍为独立Gaussian源的一侧线性插值。最后FP64近端端点和转回网络FP32后原decode使用的端点分别保存。

推理入口只接受固定字段registry和枚举张量输入，不打开真值、几何资产、旧完整分类或评价registry。prepare生成/评价角色可读真值；独立进程的推理防火墙保持开启，历史结果禁止写入。
