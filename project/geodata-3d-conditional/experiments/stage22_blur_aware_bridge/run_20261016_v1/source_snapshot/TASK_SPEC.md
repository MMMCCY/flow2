## 二、单一研究问题与方案

问题：显式处理平滑后，能否从同一属性观测提取少量准确目标条件，并使冻结Flow增加对零井隐藏对象的恢复？

唯一方案：**双属性场的有界TV去卷积 → 原固定码本判别 → 仅写入保守目标体素 → 原冻结Flow。**

不改变sigma=1、码本、通道权重、原井/地表、checkpoint、布局或源种子。不直接把观测平滑值当成纯岩性属性。不恢复所有井段，不添加任何推断的非目标硬标签。未知位置仍未知。

选择去卷积，是为了用最少新增工程处理已确认的核平均失配。它不等于完整地质反演，不强制恢复场恰好位于离散码本，不保证物性到岩性的唯一性。本轮先检验这条简单桥接是否足够。

## 三、先冻结离线方法，再看真值指标

只用case03。前处理输入为旧注册表中的保存双属性观测、固定码本、已知sigma1 Gaussian及原井/地表条件；不得读取完整真值生成ROI、初始化、背景、目标体积、阈值或正则参数。禁止使用诊断的真值q9或对象ID作为输入。原井条件当然可以使用。

设每通道固定尺度s为旧classifier的非空气码本max-min，z为待恢复属性除以s，y为观测属性除以s。对完整64³求解：

`min_z  mean((G_sigma1(z)-y)^2) + 1e-4 * TVmean(z)`

这里TVmean明确定义为：每个体素、每通道的前向三维差分向量L2范数，再对体素与通道取平均；体积外差分为0。可用sqrt(sum(diff²)+1e-8)的平滑近似，必须记录实际实现。不要无意把TV求和与数据项平均混用。

约束：各通道z限制在完整码本（含空气）的min/max除以s之间；原井/地表位置的未平滑属性固定为其观测标签查表值。不要把已平滑观测在井位直接强制成纯属性；约束施加在待恢复场z上。

G必须与旧资产生成算子一致：sigma1，原有限核半径、separable Gaussian、replicate边界；不能换成周期FFT卷积。若用梯度/伴随求解，replicate边界的伴随一般不能直接假定等于自身，使用正确自动微分或显式伴随。

初始化为有界观测z并投影原条件，单次确定性求解。不训练神经网络。MCYC选择成熟的凸优化/投影求解实现；数值步长可由算子或不读真值的下降规则确定，这是求解器设置，不是科研参数搜索。固定TV权重1e-4，最多2000次迭代；连续50次目标相对变化低于1e-6可提前终止。报告目标、数据误差、TV、约束误差和收敛曲线。未收敛或数值失败不能解释为科学方案失败；先排除数值实现问题，但不得靠真值调正则系数。

这个正则系数是本轮事先选择的工作假设，不是文献保证或最优值。若结果不理想，如实报告，不自动尝试其他系数、核或初始化。冻结方法配置后再启动完整真值评价，并保留文件时间/hash；后续不得按照真值结果选迭代快照。

## 四、只形成保守的部分目标条件

将最终恢复场乘回s，按旧非空气候选raw0…13、相同权重与固定尺度计算d_k。目标仍为raw label9。只接受同时满足的体素：

- 原分类argmin为9；
- `d9 <= 0.01`；
- `min_{k!=9} d_k - d9 >= 0.05`。

这些是固定几何筛选规则，不能称为校准概率或已验证置信度；本轮不调整阈值、不取真值最优top-k、不按真值去掉错误连通分量。

空间上只允许在旧layout的512总井布局内取新增体素，并排除原条件mask。该布局已经排除了256条holdout柱。每口井可以只有少数深度位置被接纳，其余深度保持未知。不要求凑满井数，不扩展到2048/3840，不移动井位追逐目标。不要把这些部分井段称为512口完整新增钻井。

原井和地表的值/mask永远优先。新增标签只为9；没有被接纳的位置不写入非目标、空气或恢复场argmin。生成一次条件，全部Flow源种子共用。
